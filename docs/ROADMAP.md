## 阶段 A：架构冻结

- 确认普通会话页直接运行；
- 工作台降为可选多会话界面；
- 定义 `RuntimeRegistry` 单写入者模型；
- 定义 JSONL 读取、索引和写入边界；
- 定义可编辑字段和禁止编辑字段；
- 定义备份、原子替换、审计和恢复流程。
- 定义会话删除、回收站、冲突恢复和永久删除边界。

## 阶段 B：清理现有骨架

- 以架构文档重新审查本地第一版代码；
- 将单进程 `ClaudeProc` 改成按 session 管理的 `RuntimeRegistry`；
- 删除 Pi 会话副本和 Pi 专属入口；
- 统一 Claude Code 定位、版本探测和错误输出；
- 保留默认工作区与最近工作区。

## 阶段 C：直接聊天闭环

- 扫描 `~/.claude/projects/`；
- 按工作区列出会话；
- 读取并归一化历史消息；
- 普通会话页直接 `--resume`；
- 新建、发送、停止、恢复；
- 磁盘 JSONL 与流式 UI 完成后对账。
