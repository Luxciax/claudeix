# Claudeix 开发路线

具体文件、接口、数据表、事务流程和测试清单见：

- `docs/IMPLEMENTATION_PLAN.md`
- `docs/SESSION_EDITING.md`
- `docs/SESSION_TRASH.md`

## 阶段 A：架构冻结

- 确认普通会话页直接运行；
- 工作台降为可选多会话界面；
- 定义 `RuntimeRegistry` 单写入者模型；
- 定义 JSONL 读取、索引和写入边界；
- 定义可编辑字段和禁止编辑字段；
- 定义备份、原子替换、审计和恢复流程。
- 定义会话删除、回收站、冲突恢复和永久删除边界。

## 阶段 B：清理现有骨架

- 以架构文档重新审查本地第一版代码；
- 将单进程 `ClaudeProc` 改成按 session 管理的 `RuntimeRegistry`；
- 删除 Pi 会话副本和 Pi 专属入口；
- 统一 Claude Code 定位、版本探测和错误输出；
- 保留默认工作区与最近工作区。

## 阶段 C：直接聊天闭环

- 扫描 `~/.claude/projects/`；
- 按工作区列出会话；
- 读取并归一化历史消息；
- 普通会话页直接 `--resume`；
- 新建、发送、停止、恢复；
- 磁盘 JSONL 与流式 UI 完成后对账。

## 阶段 D：工具与权限

- Bash / Read / Write / Edit 工具卡片；
- 权限确认弹窗；
- 计划、询问、接受编辑模式；
- 外部 Claude 进程检测；
- 同一 session 单写入租约。

## 阶段 E：会话内容编辑

- 用户文本编辑；
- 助手可见文本高级编辑；
- 字段白名单与 invariant 校验；
- 文件指纹冲突检测；
- 自动备份；
- 临时文件 + fsync + 原子替换；
- 编辑审计、diff 和一键恢复；
- 运行中会话禁止编辑。
- 验证 Claude Code resume 实际读取修改后的原 JSONL；
- 单次撤销、完整快照恢复和未完成事务恢复。

## 阶段 F：会话回收站

- 删除预览：完整路径、用途、数量和大小；
- 主会话与关联子代理文件事务移动；
- 回收站统一索引与内容预览；
- 原路径恢复与 SHA-256 校验；
- 相同内容去重、不同内容交换恢复；
- 默认不自动清理；
- 永久删除双重确认。

## 阶段 G：可选工作台

- 多列会话；
- 运行监控；
- 权限中心；
- 队列与广播；
- 复用普通聊天页组件，不建立第二套 runtime。

## 阶段 H：第一版发布

- Windows release 构建；
- 便携版、NSIS、MSI；
- 直接聊天、历史恢复、原文编辑恢复、删除与回收站恢复冒烟测试；
- GitHub Release；
- 收集真实反馈后再决定会话分支、worktree 和远程功能。
